
# Campus Route Finder Using Graphs in C++

## Project Objective
This project helps find routes between different campus locations using Graphs. It uses BFS to find the shortest route and DFS to display reachable locations.

## Features
- 8 campus locations
- Graph using adjacency matrix
- BFS for shortest path
- DFS for reachable locations
- Menu-driven program

## Technologies Used
- C++
- Graph Data Structure
- Queue (BFS)
- Recursion (DFS)

## Time Complexity
- BFS: O(V²)
- DFS: O(V²)
